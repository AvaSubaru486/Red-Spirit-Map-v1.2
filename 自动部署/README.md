# 一键启动本地网站

双击本目录的 **启动本地网站.exe**。启动器会显示进度，检查项目与 Python 环境，启动本地服务，确认页面、事件、人物和省级地图数据就绪，然后自动打开地图窗口。启动完成后启动器退出，网站继续在后台运行。

默认地址 `http://127.0.0.1:8010/`，仅本机可访问，不开放到局域网或公网。不需要管理员权限、PyCharm 或终端。

## 重复启动和端口占用

- 重复双击复用已有的本项目服务，不重复启动服务器。
- 8010 被其他程序占用时自动选择 8011～8030，不关闭其他程序。
- 通过项目路径指纹验证服务身份，不把其他本地网站误认为本项目。
- 实际地址与浏览器启动结果记录在 `logs/last-launch.json`。

## 运行要求

- Windows、.NET Framework 4.x（本机已有）及 Python 3.10+。
- 优先使用项目 `.venv`；没有虚拟环境时从注册表或 PATH 查找 Python 并创建。不会自动下载或把 Python 安装到 C 盘。
- 缺少依赖时自动安装 `requirements.txt`，首次安装或修复可能需要联网。环境齐全后可离线启动，网站运行时地图和数据均为本地资源。
- 使用已安装的 Edge 或 Chrome，以独立 D 盘浏览器配置目录打开，不改动现有浏览器配置。
- 必须保留整个项目目录。EXE 是项目启动器，不是内含 Python 和地图数据的独立安装包，不能单独复制到其他位置使用。

## 文件位置与排错

- `logs/launcher.log`：部署日志。
- `logs/setup.log`：环境检查与依赖安装输出。
- `logs/server-8010.log`：网站日志，其他端口有各自日志。
- `logs/last-error.txt`：最近一次失败信息，成功启动不删除旧记录。
- `logs/exe-acceptance.json`：EXE 实际运行验收结果。
- `cache/`：依赖缓存、临时文件、项目专用浏览器配置及网页缓存，全部位于 D 盘。
- `build/`：启动器编译临时文件。

启动失败弹出明确错误而非闪退。关闭网页窗口不会停止后台服务，重启电脑后需再次双击 EXE。不修改开机启动项或防火墙规则。

## 手动参数和构建

```powershell
# 自定义首选端口（诊断时不打开浏览器）
& '.\启动本地网站.exe' --port 8011 --no-browser

# 使用本机 .NET 编译器重新构建
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build_launcher.ps1
```

旧 CMD/PowerShell 入口也统一调用 EXE。`--no-dialog` 用于自动测试；`--browser-debug-port` 仅用于本机浏览器验收，正常双击不启用调试端口。

验收脚本为 `verify_launcher.py`，从真实 EXE 冷启动并连接其自动打开的浏览器，不用另行启动测试浏览器冒充验证。重跑前应只停止本项目的 8010 服务。
